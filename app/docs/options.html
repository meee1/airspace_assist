    Options and the More menu

    A tour of every setting. On the full-screen map, the More tab holds the buttons below, including Options. On the classic page they're in the buttons row. All settings are kept on the device and travel in the settings backup and file (except passwords and keys).

    Chart downloads (VNC / VTC / WAC)

    Which chart sheets download and stay on the device: the map of Australia, Tick charts in this map view, Only charts in this view, Tick charts along the flight plan, tabs and search. Default: Melbourne VNC and VTC. New sheets appear unticked, marked NEW. See Chart underlay.

    Logbook and flight logs (kept 90 days)

    Flights with GPX, CSV and ▶ replay; leg edits; totals; Logbook CSV. See Logbook.

    Google Drive

    Connect Google Drive, Save now, Restore settings, Disconnect, and Save after each flight (default on). See Google Drive.

    ADS-B traffic

    • Traffic distance: 10–100 NM (default 25).
    • Traffic symbol size: Small to Largest (default Normal).

    Spoken alerts

    Controlled or restricted airspace ahead (on), SIGMET / AIRMET ahead (on), New CTAF or area frequency (off), SARTIME (on), Checklist for the phase of flight (on), and Test the voice. See Spoken alerts.

    Radio audio and transcription

    • Audio input test: List inputs, Listen, Raw audio (on), Record 30 s, Play back, Save recording.
    • Engine: Whisper (default) or Browser speech recognition; Install offline pack; model and Download model / Delete model.
    • Transcribe the input (off), Alert when my callsign is heard (on), Check my read-back (on), Sensitivity (Low / Normal / High).
    • Transcribe the recording, Copy, Clear, and the log.

    See Radio audio and transcription.

    Settings file

    Export settings / Import settings. See Settings file.

    Top bar tiles

    • Flash CTAF and AREA when they change: number of pulses (default 5; 0 = off).
    • Every tile and alert row, with an example and two ticks (phone / tablet landscape). All on by default.
    • Tap a tile to enlarge it (on).

    See Top bar.

    Satellite imagery (Esri)

    • Tiles come through your traffic proxy when it holds an Esri key (best). Otherwise paste an Esri API key (only without a proxy), restricted to the app's site since it's visible in the page.
    • Source: World Imagery (imagery only) or Imagery with labels.
    • Opacity slider. Check key tests both sources.
    • Through the proxy, tiles you view are kept on the device (up to 6,000) and show again offline.

    NOTAMs (NAIPS) and traffic

    Not in the Options window but in its own section (the NOTAMs tab on the full-screen map):

    • Traffic proxy: the proxy address (empty = traffic off).
    • NAIPS areas, Brief in NAIPS ↗, NAIPS area page ↗.
    • Download with your NAIPS login: not available yet (awaiting Airservices authorisation).
    • NAIPS briefing: Paste from clipboard, Load briefing, Open PDF / file, Clear briefing.
    • Speak traffic alerts (on): also covers "Wires ahead".

    See Weather and NOTAMs and Traffic.

    Radio calls settings

    Aircraft type, callsign, aeroplane / helicopter, runway and Tower/CTAF choice are set in Radio calls (see Radio calls).
